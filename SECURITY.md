# Security policy

EED is under active development and is not a stable release. Do not use it to perform system installation, recovery, or rollback; those modifying workflows are not currently implemented.

## Reporting a vulnerability

Until a private reporting channel is configured, do not include credentials, personal data, or sensitive host details in public reports. The project owner should configure a private security contact before publishing a release.

## Supported versions

No stable release is currently supported. Security findings should be evaluated against the current development branch.
